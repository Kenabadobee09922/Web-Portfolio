Concept Overview

Designed and developed by John Kenneth Buhay at Systems Plus Computer College, Ecofertile demonstrates advanced proficiency in translating environmental engineering concepts into highly intuitive, operator-centric digital interfaces. Building on principles of human-computer interaction, this interface bridges multi-stage physical filtration mechanisms with clear, real-time monitoring dashboards.

The Challenge

Untreated livestock manure generates severe biohazard contamination for local waterways, produces harmful odor emissions, and results in wasted nutrient potential that could otherwise rejuvenate depleted agricultural soil.

The Filtration Concept & UI

A multi-stage separation process that isolates solid organic matter from effluent liquids, paired with an operator interface providing live telemetry on tank filtration capacity, moisture levels, and organic output readiness.

Key Interface & System Highlights

• Operator-Centric Telemetry: High-contrast graphical indicators and gauges engineered for field accessibility across tablets and rugged terminals.

• Stage-by-Stage Filtration Animations: Interactive visual feedback guiding technicians through sedimentation, active aeration, and bio-fertilizer extraction cycles.

• Responsive Glassmorphic UI: Contemporary aesthetic balancing deep dark-mode ergonomics with high-legibility telemetry readouts.

• Extensible Cloud Readiness: Component architecture structured for simple hookup to IoT telemetry brokers via Supabase or MQTT endpoints.

Design & Prototyping Methodology

The user experience began with detailed workflow sketches and high-fidelity wireframes in Figma to map operator task flows and emergency shutdown triggers. The validated prototype was then translated into a dynamic web interface using semantic HTML5, modular CSS3 transitions, and JavaScript interactions. The accompanying 3D simulation showcases mechanical movement through the system's filtration chambers.
