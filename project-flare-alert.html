Flare Alert: Real-Time Incident Reporting Engine

Designed and built to eliminate communication barriers between distressed citizens, field responders, and municipal dispatch centers.

Flutter (Dart) Firebase Auth Cloud Firestore Node.js Google Maps API Cloud Functions

Executive Summary

Serving as the Lead Developer and System Designer for this capstone project at Systems Plus Computer College, I architected the end-to-end software system from initial entity-relationship diagrams (ERDs) and Figma interactive prototypes to cross-platform Flutter client deployment and reactive Firebase backend services.

The Critical Problem

Traditional emergency hotlines suffer from call queuing delays, verbal inaccuracy in communicating coordinates, and zero real-time status feedback for the reporting citizen, leading to preventable delays during life-threatening crises.

The Engineered Solution

A streamlined mobile application capturing exact device GPS location, incident categorization, and multimedia evidence in under 3 taps, broadcasting the alert instantaneously across Cloud Firestore to nearby dispatchers and citizens.

Key System Features

• Rapid 3-Step SOS Dispatch: Intuitive emergency reporting workflow designed for high-stress situations with high-contrast UI touch targets.

• High-Precision Geolocation: Deep integration with Google Maps and Location APIs, pinning incident latitude and longitude with meter-level accuracy.

• Real-Time Community Proximity Alerts: Automated Node.js Cloud Functions calculate geographic radii to notify nearby users of active hazards.

• Lifecycle Incident Tracking: Real-time Firestore stream listeners allow the reporting citizen to track responder status from Dispatched to On Scene and Resolved.

Technical Architecture & Development Lifecycle

• Cross-Platform Client: Built in Flutter (Dart) to maximize code reuse across Android and iOS while guaranteeing 60fps native UI responsiveness.

• Distributed Cloud Data: Cloud Firestore stores reports as structured documents with indexed geospatial queries and granular security rules.

• Automated Cloud Backend: Node.js serverless functions trigger push notification payloads and maintain audit trails for emergency personnel records.
